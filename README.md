## 🚀 Quick Start

### Clone Repository

```bash
git clone https://github.com/ARIK-999/piixen-live.git
cd piixen-live
```

### Run Local Server

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
