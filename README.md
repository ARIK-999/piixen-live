🚀 Quick Start

Option 1 — Open Directly

git clone https://github.com/ARIK-999/piixen-live.git

cd piixen-live

# Open index.html in your browser

Option 2 — Local Development Server

# Python
python3 -m http.server 8080

# Node.js
npx serve .

Visit:

http://localhost:8080
